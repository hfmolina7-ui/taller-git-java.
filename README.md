TallerBasicoGit

Hernan Molina

Taller basico sobre uso y manejo de git

Aprendizajes
Uso de git y gitHub
Revisión desde la terminal

Propósito

Desarrollar un proyecto Java para practicar los conceptos básicos de Git y GitHub, incluyendo el uso de commits, ramas y sincronización con un repositorio remoto.

Instrucciones de ejecución
Clonar el repositorio.
Abrir el proyecto en IntelliJ IDEA.
Ejecutar la clase Main.java.

Comandos Git practicados

git init, git status, git add, git commit, git log, git branch, git switch, git merge, git restore, git push, git pull y git clone
